CBR Book Parser

A robust, accessible Python utility to extract and organize manga/comic pages.

Objective

The program parses a set of .cbr (renamed .zip archives containing WebP images) files inside a source directory, groups pages by chapter, and organizes them into individual directories. Each book folder is named after its source .cbr file (excluding extension) to provide an immediate 1-to-1 extraction status check.

Output Directory Tree

The parser organizes your library inside the output directory according to this template:

output/local/
└── [CBR filename without extension]/
    ├── cover.jpg
    ├── chapter_1/
    │   ├── image_1.webp
    │   └── image_n.webp
    └── chapter_n/
        ├── image_1.webp
        └── image_n.webp

Quick Start

  1. Ensure you have Python 3.14+ installed.
  2. Install the required image processing library: 
    pip install Pillow
  3. Place your .cbr files inside the source/ folder.
  4. Run the parser via terminal: 
    python parser.py --source ./source --output ./output

Development & Execution Commands

Useful execution and validation commands for users and developers:

Command Description

Naming & Conversion Details

Cover Page Extraction

The page containing [Cover] or p000 in its filename is identified as the cover image. It is converted to RGB JPEG and saved as cover.jpg at the book folder root. This ensures compatibility with local media servers like Komga, Kavita, or Calibre.

Chapter Natural Sorting

Chapters are sorted using natural sorting (e.g. c005 < c005x1 < c006) so special files and extra additions are placed in the correct chronological order. Folder names map to chapter_[number] or chapter_[number]_extra_[suffix].
